# Meeting transcript files

- `meeting-transcript-combined.md`: all three recordings in one readable, timestamped document.
- `video-N-transcript.txt`: plain text for each recording.
- `video-N-transcript.srt`: timestamped subtitle transcript for each recording.
- `video-N-transcript.json`: structured transcript for later processing.

The recordings use a mixed audio track, so speaker names cannot be assigned reliably. Review unclear names and specialized English terms against the source video before treating them as final requirements.
